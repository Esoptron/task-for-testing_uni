# GitHub Issues по найденным дефектам

По замечанию преподавателя баг-репорты должны быть заведены именно в разделе **GitHub Issues**.

После публикации репозитория создайте 2 issue из шаблонов:

1. `.github/ISSUE_TEMPLATE/bug_001_card_number_17_digits.md`
2. `.github/ISSUE_TEMPLATE/bug_002_negative_transfer.md`

## Что уже добавлено в репозиторий
- Готовые issue-шаблоны с полным описанием, шагами и ожидаемым/фактическим результатом.
- Дублирующая документация в `docs/bugreports/*` для удобства проверки.
