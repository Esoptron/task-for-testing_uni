# BUG-001: Поле номера карты принимает 17 цифр

- **Серьёзность:** Major
- **Приоритет:** High
- **Окружение:**
  - OS: Ubuntu 24.04 LTS (x86_64)
  - Browser: Google Chrome 136.0.7103.113 (headless)
  - App build: `dist/index.html` (local file URI)

## Шаги воспроизведения
1. Открыть приложение.
2. Выбрать счёт **"Рубли"**.
3. В поле "Номер карты" ввести 17 цифр.

## Ожидаемый результат
Поле принимает максимум 16 цифр.

## Фактический результат
Поле сохраняет 17 цифр.

## Влияние
Нарушение базовой валидации платёжных реквизитов.
