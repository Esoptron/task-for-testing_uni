# BUG-001: Поле номера карты принимает 17 цифр

- **Серьёзность:** Major
- **Приоритет:** High
- **Окружение:** Linux, Chrome/Chromium

## Шаги воспроизведения
1. Открыть приложение.
2. Выбрать любой счёт.
3. В поле "Номер карты" ввести 17 цифр.

## Ожидаемый результат
Поле принимает максимум 16 цифр.

## Фактический результат
Поле сохраняет 17 цифр.

## Влияние
Нарушение базовой валидации платёжных реквизитов.
