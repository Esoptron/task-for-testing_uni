# BUG-002: Сервис принимает отрицательную сумму перевода

- **Серьёзность:** Critical
- **Приоритет:** Highest
- **Окружение:**
  - OS: Ubuntu 24.04 LTS (x86_64)
  - Browser: Google Chrome 136.0.7103.113 (headless)
  - App build: `dist/index.html` (local file URI)

## Предусловия
1. Открыта страница сервиса.
2. Выбран счет **Рубли**
3. Введет корректный номер карты из 16 цифр.

## Шаги воспроизведения
1. Ввести в поле суммы значение -1000
2. Проверить доступность кнопки **Перевести**

## Ожидаемый результат
Отрицательная сумма не должна приниматься. Кнопка перевода должна быть недоступна либо должно появляться сообщение валидации.

## Фактический результат
Кнопка перевода доступна, операция принимается, показывается alert об успешном переводе.

## Влияние
Потенциально некорректные финансовые операции и нарушение бизнес-правил.
